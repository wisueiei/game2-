# UNDERFALL — พื้นและดอกไม้ R00 รุ่นเก็บรายละเอียด

> Summary: หย่อมพื้นสีเงียบและดอกไม้แยกจากภาพv1bสำหรับฉากแบ่งเลเยอร์ โดยไม่เปลี่ยนผังหรือภาพต้นฉบับ

รุ่นนี้แก้ปัญหาพื้นที่ตัดติดหิน/ใบไม้จนซ้ำเป็นตาราง ใช้ RGB จากภาพv1bเดิม คัดหย่อมพื้น16pxหรือ8pxที่สงบ; หย่อม8pxขยาย nearest-neighbor2เท่า ไม่มีสีใหม่และไม่ย้ายทาง/สะพาน/หน้าผา ต้นไม้และตัวละครยังแยกเป็นสไปรต์

ดู [manifest](manifest.json) สำหรับrectต้นทาง/ค่าตรวจพื้น/ดอกไม้/alpha และ [งานสร้าง CH00](../../../design/chapters/ch00-runtime.md) สำหรับผลเดินจริง รูปต้นฉบับไม่ได้ถูกแก้

ทำซ้ำด้วย `tools/refine-r00-surfaces.py` แล้ว `tools/build-ch00.cjs` อย่ารันgeneratorผู้เล่นหรือสร้างผังใหม่เพื่อใช้ไทล์นี้
