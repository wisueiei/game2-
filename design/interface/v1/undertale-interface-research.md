# UNDERFALL — ข้อมูลเมนู Undertale ที่ใช้อ้างแบบ

> Summary: แยกปุ่มและหน้าของUndertaleจากการดัดแปลงUNDERFALL พร้อมแหล่งอ้างอิงและข้อจำกัดการนับหน้า

ตรวจเว็บ9ตุลาคม2026 ไม่มีการนำสไปรต์/เสียงต้นฉบับมาดาวน์โหลดลงเกมนี้
ข้อมูลที่ค้นคือระบบหน้าจอ ไม่ใช้ทฤษฎีคอมมูนิตี้เพิ่มcanonหรือเปลี่ยนบทที่ผู้เขียนเลือกแล้ว

## ปุ่มหลักและหน้าย่อย

| บริบท | ต้นฉบับ | จุดที่นำมาใช้ / แหล่ง |
|---|---|---|
| เปิดเกมเมื่อมีSAVE | Continue / Reset / Settings รวม3ตัวเลือก; มีหน้าต้อนรับ/ตั้งชื่อและรูปเมนูเปลี่ยนตามความคืบหน้า | ของเราเป็นเริ่มใหม่/เล่นต่อ/ประวัติ ตั้งค่าแยกจุดเข้า; ไม่เปิดรูปตัวละครตามปมก่อนเวลา [Main menu](https://undertale.wiki/w/Main_menu) |
| เมนูระหว่างเดิน | ITEM / STAT / CELL รวม3หมวด | ของเรารวมของ/โทร/สถานะในโทรศัพท์ตามstory ไม่อ้างว่าต้นฉบับอ่านกระเป๋าจากโทรศัพท์ [Menu](https://undertale.wiki/w/Menu), [Cell Phone](https://undertale.wiki/w/Cell_Phone) |
| ITEMและอุปกรณ์ | กระเป๋ามี8รายการ ใส่อาวุธและชุดได้ มีคลังกล่องแยก | เราใช้รายการเลื่อนและไม่จำกัด8ช่องในสองCH กล่องเก็บเป็นUIอนาคต ไม่เพิ่มข้อจำกัดใหม่ [Item](https://undertale.wiki/w/Item), [Dimensional Box](https://undertale.wiki/w/Box) |
| STAT | HP/AT/DF/เงิน/อุปกรณ์และLV/EXPเกี่ยวกับกลไกต้นฉบับ | สองCHเราแสดงHP/DF/G/ของจริง ไม่ใส่การเพิ่มLV/EXPหรือคะแนนความดีเอง [Stats](https://undertale.wiki/w/Stats) |
| ต่อสู้ | FIGHT / ACT / ITEM / MERCY รวม4คำสั่ง; ACTแตกตามมอน, MERCYมีไว้ชีวิต/หนีตามเงื่อนไข; มีช่วงหลบกระสุน | แยกเทิร์นตัวผู้เล่นกับหัวใจตามแบบเรา; Xที่หน้าMERCYเป็นสัญลักษณ์ ไม่ผูกปุ่มพลังX [Encounter](https://undertale.wiki/w/Encounter), [เว็บไซต์ทางการ](https://undertale.com/about/) |
| ร้านค้า | เมนูซื้อ/ขาย/คุยและออก; ส่วนใหญ่ปฏิเสธซื้อของจากผู้เล่น มีข้อยกเว้นTemShop | ออกแบบทั้งBUY/SELL/TALK/EXIT แต่ร้านแมงมุมตัวอย่างไม่รับซื้อ ไม่มีราคาขายที่แต่งเพิ่ม [Vendor](https://undertale.wiki/w/Shops) |
| SAVE/เกมโอเวอร์ | เซฟช่วยคืนHP โหลดย้อนจุดบันทึก และRESETเป็นอีกการกระทำ | เราแยกcommit/โหลด/เริ่มใหม่/ล้มเหลว/กู้สำรองตามstory ไม่สร้างRESETในเนื้อเรื่องจากปุ่มUI [SAVE](https://undertale.wiki/w/SAVE), [Game Over](https://undertale.wiki/w/Death) |
| ตั้งชื่อ | มีหน้ากรอกและยืนยันชื่อ มีเงื่อนไขชื่อเฉพาะในต้นฉบับ | ของเรารับไทย1–12graphemesหลังเข้ามิติ ไม่ยกการห้ามชื่อ/HardModeมาใช้โดยไม่ได้รับคำสั่ง [Name](https://undertale.wiki/w/Name) |
| Settings | ตัวเลือกขึ้นกับแพลตฟอร์ม/รุ่น เช่นภาษาและตั้งค่าจอย/ทดสอบปุ่ม | เรามีเสียง/คู่มือปุ่ม/อ่านง่าย/ลดmotion ไม่อ้างว่ามีgamepadหรือบทแปลอังกฤษพร้อมแล้ว [Settings](https://undertale.wiki/w/Settings) |

จำนวน3/4ข้างต้นเป็นกลุ่มคำสั่งหลัก ไม่ใช่จำนวนปุ่มทุกปุ่มในทั้งเกม
การแยกจำนวนหน้าของงานนี้เป็นการจัดหมวดของCodex: wikiมีเมนูเปลี่ยนตามprogressและหน้าย่อยตามบริบท จึงไม่อ้างเลข“จำนวนหน้าofficial”ตายตัว
คู่มือdemoเป็นหลักฐานประกอบเรื่องหมวดเมนู/ระบบ แต่ไม่ถือว่าdemoเท่าทุกรุ่นทุกแพลตฟอร์ม [Manual](https://undertale.wiki/w/Manual)

## ส่วนที่เป็นสไตล์และระบบของเรา

ขาวอุ่น/คราม/ชมพู/ฟ้าวิญญาณ กรอบคม โลโก้พิกเซลที่วาดเป็นUIเอง ThaiDOM และสไปรต์R5ที่ผู้เขียนรับรอง
คลังตอนครบรอบ ความทรงจำ บ้านVoid สัตว์เลี้ยง หนังสือเวทหลังแซน และPacifistที่เป็นเส้นฆ่าบ้าง ไม่ใช่กฎต้นฉบับ
หน้าระบบอนาคตมีเพียงโครงUI/ข้อมูลทดลอง ห้ามถือว่าได้กำหนดเควส เงื่อนไขปลด หรือเนื้อหาSS2แล้ว
