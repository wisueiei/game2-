ภาพที่เลือกใช้ล่าสุด 9 ตุลาคม 2026: [v1 — ภาพป่าถึงปราสาทราชา](2026-10-08-v1/README.md) โดย CH00 ใช้ R00 ฉบับ v1b ตามภาพต้นทางและผังโลกเดียว

รุ่นก่อนการเลือกภาพล่าสุด: [v2](2026-10-08-v2/README.md) / [LEVEL_LAYOUT.md](2026-10-08-v2/LEVEL_LAYOUT.md) เก็บเป็นที่มาของข้อเสนอทางกว้างและพื้นที่ภายใน
