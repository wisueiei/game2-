# UNDERFALL — ชุดภาพร่างแมพ ป่าถึงปราสาทราชา

วันที่8ตุลาคม2026  
สถานะ: **ภาพต้นทางที่เลือกใช้; CH00 R00 กำลังสร้างฉาก 2D แบ่งชั้นตามผัง v1b และรอผลตรวจใหม่ ภาพแมพเต็มเป็นภาพอ้างอิง/debug ส่วนพื้นที่อื่นยังเป็นงานออกแบบ**

## เส้นทางที่ใช้จัดภาพ

**R00ป่าก่อนมิติ → รอยแยก/ตกครั้งที่สอง → R01รูน → R02หิมะ → R06ทุ่งโคม(ตำแหน่งเสนอ) → R03น้ำตก → R04เขตทดลอง → R07สถานี(ตำแหน่งเสนอ) → R05เมืองใกล้วัง/ปราสาท**

เส้นฐานR01→R02→R03→R04→R05อ้างโครงเดิม ชื่อ/จุดแทรกR06กับR07ยังเป็นข้อเสนอที่ใช้ลองภาพ ไม่ยกให้เป็นการยืนยันพล็อตโดยอัตโนมัติ
บ้านทอเรียลอยู่ในR01 ไม่ใช่บ้านVoidของชิกุ
ห้องอีกเส้นเวลาเป็นพื้นที่ย่อย ไม่ใช่เมืองหลักเพิ่ม และไม่เปลี่ยนชิกุตัวจริงผ่านขวดให้เป็นผู้ทดลองอีกคน

## สัญลักษณ์สำหรับผู้เขียน

- **C / กล่องไม้ทอง:** จุดวางไอเทมที่ซ่อนหรือของที่มีในบทเดิม
- **M / เศษฟ้า:** ตำแหน่งเสนอเศษความทรงจำ ไม่ใช่ชิ้นส่วนร่างกายหรือวิญญาณของราชา
- **S / ดาวทอง:** จุดพัก/เซฟที่เสนอ ต้องเทียบเงื่อนไขเกมจริงก่อนสร้าง
- **D / ทางหรือประตูลับ:** จุดซ่อนทั่วไป; เฉพาะทางอีกเส้นเวลาที่R06/R07ตามภาพ11จึงเป็นทางไปพบอีกคน
- **MAIN RIFTในR00:** รอยแยกเหตุการณ์ฟิวโจมตี ไม่ใช่ประตูหินถาวรหรือห้องพบชิกุอีกคน
- **ประตูปิดในปราสาท:** ประตู/กำแพงตามเรื่องปลายทาง ไม่ใช่ทางลัดไปอีกเส้นเวลา

ป้ายC1/M1/S1/D1เป็นเครื่องหมายเพื่อออกแบบ ไม่ใช่HUDที่แสดงให้คนเล่นเห็นจริง เมื่อนำไปสร้างให้ซ่อนป้ายแล้วใช้แสงจาง รอยผนัง รากไม้หรือทางอ้อมเป็นเบาะแส
รหัสป้ายซ้ำในต่างภาพไม่ใช่ของชิ้นเดียวกัน ต้องมีnamespaceเช่นmap01_C1/map02_C1ในระบบจริง

## การวางความลับ

- มีทางหลักที่เห็นจุดหมาย และทางแยก/ทางวนให้กลับมาสำรวจ ไม่ขยายเป็นที่ว่างเปล่า
- กล่องซ่อนหลังรากไม้/ท่อนไม้ ผนัง/ชั้นหนังสือ ใต้น้ำตก ใต้สะพาน หลังเวที หรือซอกของเก่า
- เศษความทรงจำใช้ตำแหน่งและเอฟเฟกต์เป็นplaceholderเท่านั้น **ไม่แต่งเหตุการณ์จริงของผู้เขียนกับคนรัก**
- จำนวนป้ายในภาพไม่ยืนยันจำนวนไอเทมทั้งหมด ราคา ค่าพลัง เควสบังคับ หรือเงื่อนไขGood
- Mในป่าก่อนมิติเป็นตำแหน่งเสนอ/การปู ยังไม่กำหนดให้CH00เก็บความทรงจำจริงก่อนสูญเสียความจำ
- กล่องมัฟฟิ้น/แหวนสวนที่มีในCH00ยังใช้ผลจากstory.md ไม่เปลี่ยนเป็นไอเทมใหม่จากภาพ
- รองเท้าสีขาวรับจากทอเรียลเมื่อเข้ารูนตามบท10.15.1 ไม่ย้ายเป็นรางวัลกล่องในบ้านเพราะเห็นกล่องในภาพ03

## พื้นที่ทับซ้อน — ภาพ05/08/11

1. ร่างทางแรก: R06บริเวณสะพาน/ต้นไม้กลวง → FIELD ECHOที่สีซีด เงาหรือพื้นไม่ตรง → VOID ROOM A → กลับทางเข้าR06เดิม
2. ร่างทางครั้งถัดมา: R07นาฬิกา/ช่องซ่อมสถานี → STATION ECHO → VOID ROOM B/เอกสารทดลอง → กลับR07เดิม

สองแถวนั้นเป็นคนละการพบ ไม่เป็นทางใช้ข้ามR06ไปR07เพื่อเลี่ยงน้ำตก/แล็บ ไม่ใช้บ้านชิกุตัวจริงแทนห้องผู้ทดลอง
ตัวเล็กในห้องเป็นplaceholderของอีกเส้นเวลา ไม่ใช่หยวนผมดำ/จิ้งจอกเก้าหางจากขวดหรือVOID ECHOที่เกิดระหว่างการลบ
วิธีเปิดทาง เวลาที่ปลดล็อก บทที่เล่า ของที่ได้รับ และผลต่อSS2ยังต้องเลือก ไม่ถือว่าการเข้าไปเท่ากับยินยอมทดลองDetermination
ทางกลับต้องเป็นทางเดิน/ประตูที่ใช้ได้จริงเมื่อสร้าง ไม่แก้ช่องว่างพื้นด้วยการเพิ่มสกิลกระโดดที่ยังไม่ได้วางไว้

## สิ่งที่ตรวจแก้แล้ว

- ภาพ00แก้ลูกศรให้R04แล็บต่อR07สถานี ไม่เชื่อมตรงR06→R07
- ภาพ01เปลี่ยนประตูหินเป็นรอยแยกชั่วคราวลอยในอากาศ มีป้ายMAIN RIFTสำหรับงานออกแบบ
- ภาพ02แก้ห้องสัญลักษณ์ท้ายรูนเป็นฟ้า/วงกลม แดง/สามเหลี่ยม เขียว/ดาว ตามch01.md
- ภาพ04เปลี่ยนช่องม่วงในถ้ำหิมะเป็นกล่องC4ในถ้ำธรรมดา ไม่เพิ่มการพบชิกุอีกคนก่อนR06
- คัดลอกPNGที่เลือกเข้าโปรเจกต์และตรวจSHA256ตรงกับผลสร้างต้นทาง
- ตัวอ่านเครื่องมือขัดข้องช่วงแก้ครั้งแรก จึงลองใหม่ด้วยเครื่องมือในตัวจนได้ครบ ไม่สลับCLIหรือใช้API key

## ขอบเขตที่ยังไม่ใช่งานสร้างเกม

ภาพเป็นผังมองกว้างหลายหน้าจอ ไม่ใช่viewport400×225จริง ไม่ยืนยันcollision/ทางเดิน/ปริศนาหรือการเข้าถึงของทุกชิ้นผ่านการเล่นแล้ว
แมพใหม่ยังเป็นgeometryเสนอ โดยเฉพาะบันได ชั้นล่าง ประตู ทางวนและจุดซ่อน ไม่ใช้แทนลำดับ/เงื่อนไขCH00–CH01โดยไม่ประสานบท
NPC/ผู้เล่นตัวเล็กแสดงสเกลและจุดเหตุการณ์ ไม่ใช่การติดตั้งสไปรต์สุดท้ายหรือให้NPCตัวเดียวเกิดพร้อมกันสองที่
ดาว/กล่อง/เงาในVoidยังต้องใช้กฎVoidของโครงเรื่อง ไม่มีการกำหนดความจำเมื่อRESETหรือการคงอยู่ของสัตว์เลี้ยงจากภาพนี้
การผสมโรงงาน/ภูมิทัศน์ร้อนในR04เป็นข้อเสนอด้านภาพ ไม่เพิ่มพล็อตHotlandหรือระบบทนลาวาเอง
ไม่มีภาพเปิดกำแพง/ออกสู่แสงตะวันหรือเรื่องSS2 การเดินทางในชุดนี้หยุดที่ปราสาท
