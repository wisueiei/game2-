# UNDERFALL — แมพ v2: ทางกว้าง ลานชม และอาคารเข้าได้

> **ชุดอ้างอิงปัจจุบัน:** ปัจจุบัน: UNDERFALL — แมพ v2: ทางกว้าง ลานชม และอาคารเข้าได้; อ่านdesign-currentเพื่อเลือกเวอร์ชันและไม่อ้างภาพเป็นruntime อ่าน [design-current.md](../../../design-current.md) เพื่อเลือกเวอร์ชันและแยกข้อยืนยัน/ค่าตั้งต้น/งานที่ยังไม่สร้าง; [INDEX.md](../../../INDEX.md) เป็นทางเข้าเอกสารทั้งหมด

ภาพสร้าง2026-10-08 · เอกสารซิงค์2026-10-09 · ใช้สไตล์v1ที่ผู้เขียนเลือกเป็นฐาน
สถานะ: **ภาพออกแบบ ไม่ใช่แมพที่เล่นได้แล้ว**; CH00-r2/CH01-r4ซิงค์ผังแล้ว แต่ยังไม่แก้เกม/ติดตั้งภาพ

## รอบนี้เปลี่ยนอะไร

- ขยายพื้นทางเชื่อมอีกประมาณ 25% จากภาพกลางงาน และเพิ่มพื้นที่เดินในลานที่เลือกประมาณ 45% คงสเกลผู้เล่น/ภาพพิกเซลเดิม
- มีลานพักต่างจากซอกของลับ: เมืองหิมะ ทุ่งโคม น้ำตก สถานี เมืองราชา และสวนบางจุด
- วางปริศนาเปิดทางเป็นช่วงๆ ไม่บังคับทุกห้อง และไม่ให้ร้าน/ทางวนข้ามเหตุการณ์สอนหรือเหตุการณ์หลัก
- เพิ่มประตูอาคารธรรมดา E พร้อมผังภายในบ้านแซน–ปาปิรัส กิวบี้ โรงแรม ร้านหิมะ บ้านอันดาย ร้านน้ำตก ร้านชา คาเฟ่ ของเก่า พัสดุ ห้องสมุด และร้านอะไหล่
- คงแผงลอยบางร้าน คงเส้นลับไปอีกเส้นเวลา และไม่สับสนบ้านตัวหลักกับบ้าน Void ของชิกุ

ภาพ AI แสดงการขยายโดยประมาณ **ยังไม่ได้วัด collision ว่าได้เปอร์เซ็นต์จริง** ดูสูตร/ขนาดตัวอย่าง/รายการทดสอบในใบส่งต่อ
คำขอเรื่อง “เข้าอาคารได้” ยืนยันแล้ว แต่ผังห้องและเงื่อนไขเชิญเข้าบ้านเป็นแบบเสนอ ไม่ยืนยันเรื่องราวใหม่จากภาพ
ชื่อ/จุดแทรก R06/R07 ยังเป็นข้อเสนอเดิม ไม่เปลี่ยนเป็น canon ด้วยการมีภาพ

## อ่านสัญลักษณ์ให้ถูก

C = จุดกล่องเสนอ; M = เศษความทรงจำ/เบาะแสเสนอ ไม่เขียนเหตุการณ์คู่รักแทนผู้เขียน
S = ดาวพัก/SAVE ที่เสนอ; P = ปริศนา; E = ประตูอาคารเดินเข้าได้; D = ทางลับ (ไม่ใช่ทุก D เป็น Void)
ตัวอักษรเหล่านี้เป็นเครื่องหมายของผังผู้เขียน ไม่ต้องเอาไปแสดงทุกจุดในเกม
เลขซ้ำกันข้ามพื้นที่ใช้ roomId/namespace แยก อย่าใช้ P1 หรือ E1 เป็น flag รวมทั้งเกม
MAIN RIFT ป่า = รอยแยกจากฉากโจมตี; ประตูสีม่วงในปราสาท = barrier ตามเรื่อง ไม่ใช่ประตูพบอีกคน

## จุดที่ภาพไม่ใช่คำตอบสุดท้าย

- ทางวนในภาพคือโครงชมพื้นที่ ไม่ใช่ collision ที่เปิดเสมอ ห้องสอนรูนและจุดต่อโรงงานต้องมี gate ตามใบส่งต่อ แม้ภาพยังวาดพื้นสะพานต่อกันอยู่
- R04 จุด E2 เป็นตำแหน่งร้านข้างเคาน์เตอร์ ต้องวางประตูห้องร้านจริงตอนสร้าง ไม่วาร์ปผู้เล่นผ่านโต๊ะ
- R03 ร้านป้ายปลาในแมพเป็น E2 ตามทะเบียน แม้ตัวอักษร E2 ไม่ชัดในภาพ
- ป้ายร้านกิวบี้ในภาพ exterior อาจสะกด GRILBY'S; ใช้ชื่อ GRILLBY'S / กิวบี้ จากผังภายในและทะเบียน ห้ามถือคำบนภาพ AI เป็นบทที่ถูกต้องทุกคำ
- จำนวนหนาม/ไทล์/ใบไม้ที่วาดไม่แทนตาราง CH01; สีท้ายรูนคงฟ้าวงกลม/แดงสามเหลี่ยม/เขียวดาว
- รูปผู้เล่น/มอนตัวจิ๋วเป็นตัวเทียบขนาด/คนละจังหวะฉาก ไม่เปลี่ยนโมเดลที่เลือกไว้ ไม่ทำให้แซน/อันดายมีตัวซ้ำหลายห้องพร้อมกัน
- ผังโรงแรม/ครัว/อาหาร/ร้านยังไม่กำหนดราคา ค่าสถานะ หรือเงื่อนไข Good ใหม่
- โรงงานหลายสะพานยังต้องปิด collision ทั้งเส้นเมื่อไฟยังไม่ต่อ; gate/ไฟในภาพไม่ใช่ผลทดสอบว่าสามารถเดินผ่านหรืออ้อมได้จริงแล้ว
- บ้านทอเรียลและผังไปอีกเส้นเวลาคงภาพเดิมเพื่อรักษาเรื่อง; ทางย่อยเหล่านี้ไม่บังคับเพิ่ม 45% ทั้งหมด
