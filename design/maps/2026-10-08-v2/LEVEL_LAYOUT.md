# UNDERFALL — แผนพื้นที่เดิน ประตูปริศนา และอาคารเข้าได้ v2

> **ชุดอ้างอิงปัจจุบัน:** ปัจจุบัน: UNDERFALL — แผนพื้นที่เดิน ประตูปริศนา และอาคารเข้าได้ v2; อ่านdesign-currentเพื่อเลือกเวอร์ชันและไม่อ้างภาพเป็นruntime อ่าน [design-current.md](../../../design-current.md) เพื่อเลือกเวอร์ชันและแยกข้อยืนยัน/ค่าตั้งต้น/งานที่ยังไม่สร้าง; [INDEX.md](../../../INDEX.md) เป็นทางเข้าเอกสารทั้งหมด

วันที่: 2026-10-08
สถานะ: งานออกแบบและภาพพรีวิว ยังไม่สร้างแมพ/collision/ประตูในเกม

## 1. สิ่งที่ผู้เขียนยืนยัน และสิ่งที่ยังเป็นแบบเสนอ

ตกลงแล้ว: ใช้สไตล์ภาพชุด v1 ต่อไป; ขยายพื้นที่เดิน; มีลานกว้างในบางแมพ; มีปริศนาเปิดทางเป็นช่วงๆ; จังหวะเรื่องคล้าย Undertale; เพิ่มทางเชื่อมอีก 25% และพื้นที่เดินในลานชมวิวที่เลือกอีกประมาณ 45%; ร้านบางแห่งและบ้านตัวละครหลักเข้าไปเดินด้านในได้ เช่น ร้านกิวบี้ บ้านแซน และบ้านอันดาย

แบบเสนอสำหรับการสร้าง: ขนาดพื้นในตาราง, รูปแบบปริศนาใหม่หลังรูน, ตำแหน่งประตู/ห้อง/ร้านใหม่ และเงื่อนไขเชิญเข้าบ้าน ยังไม่ใช่บทหลักที่ยืนยันแล้วทุกจุด
ชื่อ R06 “ทุ่งโคมลอย” และ R07 “สถานีลืมเวลา” รวมถึงตำแหน่งแทรกยังเป็นชื่อ/จุดวางเสนอเหมือนเอกสารก่อนหน้า

ไม่เปลี่ยนบทพูด ลำดับฉาก คำตอบปริศนา CH01 หรือเงื่อนไขตอนจบโดยอัตโนมัติ การมีแบบบ้านไม่หมายความว่าผู้เล่นเป็นเพื่อนกับเจ้าของบ้านแล้ว

## 2. สัดส่วนพื้นที่ — วัดพื้นเดิน ไม่วัดขนาด PNG

ตีความ 25% เป็น **ความกว้างสุทธิของทางเชื่อม** และ 45% เป็น **พื้นที่เดินสุทธิของลานที่เลือก** ไม่ใช่เพิ่มความกว้างและความยาวทั้งคู่ 45% และไม่ขยายทุกห้องเท่ากัน
แปดภาพกลางงานที่ขยายรอบแรกแล้วเป็นฐานของคำขอ “เพิ่มอีก”; ปราสาทภายในซึ่งยังไม่สร้างรอบกลางใช้ภาพ v1 เป็นฐาน ปริมาณในภาพ AI เป็นการประมาณทางสายตา ไม่ใช่หลักฐานเปอร์เซ็นต์จาก collision

สูตรตอนสร้าง: targetPathWidth = baseClearWidth × 1.25; targetScenicArea = baseWalkableArea × 1.45
ต้องบันทึก baseClearWidth/baseWalkableArea ของผังที่เลือกก่อนปรับจริง และวัดหลังหักพื้นที่อาคาร น้ำ ต้นไม้ เฟอร์นิเจอร์ และสิ่งกีดขวางออกแล้ว

| token / หน้าที่ | ฐานตัวอย่าง (logical px) | เป้าหมาย | วิธีตรวจ |
|---|---:|---:|---|
| path-main | 64 กว้าง | 80 กว้าง | ช่องเดินโล่งต่อเนื่อง ไม่รวมพุ่ม/ขอบน้ำ |
| path-bridge / stair-main | 96 กว้าง | 120 กว้าง | ราวสะพานไม่กินขนาดสุทธิ |

| interior-aisle | — | ไม่น้อยกว่า 64 กว้าง | เดินรอบโต๊ะได้ ไม่ต้องเบียด NPC |

ตัวเลขเป็นแบบตั้งต้น **ไม่ใช่ค่าที่วัดได้จากเกมปัจจุบัน** ภาพผัง 1536×1024 ไม่ใช่โลกขนาด 1536×1024 โดยอัตโนมัติ
คง viewport เกม 400×225 และสเกลผู้เล่นเดิม ใช้โลกกว้างขึ้น/กล้องเลื่อน ไม่ซูมออกจนตัวละครและตัวหนังสือเล็ก
ใช้พื้น/ผนัง tile 16 logical px ได้ แต่ขอบ collision ต้องปรับได้ตามความกว้างสุทธิ ไม่ปัดลงจนทางไม่ถึงเป้า

ยังไม่เพิ่มแสงตะวันจริงก่อนเปิดมิติ ป่าจริงยังมืดตามขวด/ละออง/X; ภาพผู้เขียนเห็นทั้งแมพเพื่อออกแบบได้

## 3. จังหวะเดินเรื่อง

ใช้จังหวะ **พบคน → สำรวจ → ปริศนาหรือเผชิญหน้า → จุดพัก/ร้าน/บทคุย → เบาะแส → เหตุการณ์หลัก**
ไม่ใช้ทุกห้องเป็นประตูล็อก และไม่เปลี่ยนทุก NPC ให้ต้องสู้ทันที ลาน ร้าน บ้าน และ SAVE เป็นจุดให้ความสัมพันธ์มีเวลาหายใจ
ปริศนาหนึ่งชุดต้องมีป้าย/ตัวละครสาธิต → ให้ลอง → แปรรูปเล็กน้อย; ผิดแล้วลองใหม่อย่างปลอดภัย ไม่ใช้ปริศนาเพื่อบังคับตายเกิด

ลำดับฐาน: R00 → รอยแยก/ตกครั้งสอง/ตำนาน/ตั้งชื่อ → R01 → R02 → R03 → R04 → R05
ร่างที่รวมพื้นที่ชิล: R01 → R02 → R06 → R03 → R04 → R07 → R05; ไม่อ้างว่าจุดแทรกได้รับการยืนยันใหม่แล้ว

### R00 — คุ้นเคย อบอุ่น และรอยแยก

จุดตก/เจ็บ–ไม่เจ็บ → เดิน/ขวด → ฝึก C กับรากไม้ → ป่าขยาย/คำถามความจำ → คนใส่หมวก → สองแขนง → รอยแยก
ทางช่วยไปการโจมตีโดยตรง; ทางไม่ช่วยไปสวน V/แหวน/N ก่อนกลับมาโดนโจมตี ทั้งสองไป CH01 ได้
แหวนชุบชีวิตหนึ่งครั้งต่อแหวน/N ไม่ใช่กุญแจบังคับของบทหลัง ห้ามทำประตูที่ผู้เลือกช่วยผ่านไม่ได้
M ในป่าภาพเป็นตำแหน่งเบาะแสเสนอ ไม่เขียนความทรงจำจริงของคู่รักเอง และไม่ยืนยันการเก็บ memory ก่อนสูญเสียความจำ

### R01 — อ้อมกอดแรกและการลองเดินเอง

CH01 เป็นตัวคุมลำดับ: ฟลาววี่ → ทอเรียลช่วย → ทางเข้า/รองเท้าสีขาว → แผ่นกด/สวิตช์/หุ่น/หนาม → โถงเดินเอง → โทรศัพท์ → สำรวจปริศนา/มอน/ร้าน → บ้าน → ศึกและจากลา
ลานใบไม้กว้างขึ้นเพื่อคุย Froggit อ่านป้าย แวะขนมและ SAVE แต่ทางไปปลายรูนยังผ่านเหตุการณ์ตามบท
ห้องเบเกอรีใหม่เป็นพื้นที่ย่อยของร้านแมงมุมเดิม ใช้ stock/รายการซื้อชุดเดียวกับหน้าร้าน ไม่สร้างการรับรางวัลซ้ำ
บ้านทอเรียลและโถงจากลาคงแบบเดิม ปลอดภัย ไม่มีปริศนาบังคับกินข้าว/พัก และไม่มีทางสวนลัดข้ามศึก

### R02 — เริ่มเป็นเพื่อน แล้วมีเมืองให้กลับมาเยี่ยม

ออกจากรูน → พบแซน → ??? มอบหนังสือเวท → ทางหิมะ/ปริศนาปาปิรัส → เมือง/เผชิญหน้าตามบท → เยี่ยมบ้านและร้านเมื่อถึงช่วงที่อนุญาต → พื้นที่ถัดไป
ลานแซนและลานเมืองเป็นคนละจุดทางอารมณ์ แซนไม่จำทุก RESET; บ้านไม่เป็นเฉลยระบบเวลาทั้งหมดทันที
กิวบี้เป็นร้านที่เข้าไปเดินหาที่นั่ง คุยกับเจ้าของ/ลูกค้า และเปิดเมนูซื้อเมื่อกดคุย ไม่เปิดหน้าร้านแทน interior

### R06 — เดินชมและสังเกตสิ่งผิดปกติ

ร้านชา/คนท้องถิ่น → สนามหญ้า/โคม/ริมน้ำ → เควสเล็กตามที่ผู้เขียนจะเติม → เบาะแสต้นไม้ → หลุดเข้าทางหลังต้นไม้ → SX03พบชิกุอีกเส้นเวลาและเห็นหน้า/ตัวครั้งแรก → กลับจุดเดิม

ผู้เขียนยืนยันว่าเขาคือเจ้าของเสียงจากVoidที่แทรกตอนตก/ถามชื่อ10.1และ10.11คนเดียวกัน ก่อนฉากพบหลังต้นไม้ห้ามวางportrait เงาร่าง หรือspriteของเขาให้เห็นจากแมพปกติ/ช่วงตั้งชื่อ ค่อยเปิดที่ฉากพบในพื้นที่ทับซ้อน ไม่รวมเสียงนี้กับชิกุตัวจริงผ่านขวด ชื่อR06/จุดแทรกในเมืองและพิกัดยังเป็นข้อเสนอ
เส้นหลักไม่ต้องผ่านมิติหรือทำร้านชาครบ ปริศนาโคมอยู่ทางลับ ไม่บังคับผู้เล่นทุกคนแก้

### R03 — ตำนานกับความระแวง

มาเรีย/เรื่องของชุมชน → ทางดอกไม้เสียงสะท้อน/ภาพสงคราม → สำรวจริมน้ำ → อันดาย/หน้าที่ตามบท → เปิดเส้นทางไปแล็บ
บ้านอันดายเป็นพื้นที่สร้างความสนิทภายหลัง ไม่เข้าบ้านระหว่างถูกไล่ล่าโดยไม่มีเหตุให้เธอยอมรับ
น้ำตกให้เวลาอ่านหลักฐาน แต่หลักฐานแต่ละชิ้นไม่เฉลยริน ชิกุ และพลังความเกลียดชังพร้อมกัน

### R04 — ความสนุกหน้าฉากและความเศร้าหลังฉาก

อัลฟี่/คิน → ระบบควบคุม/เวทีครั้งแรก → เอกสารและผู้ทดลองใต้แล็บ → เวทีถัดไปตามเหตุการณ์ → ออกจากเขต
ลานต้อนรับกับพื้นชมเวทีเป็นจุดคุย; B1 เป็นผู้มีชีวิตที่ต้องได้รับความช่วยเหลือ ไม่วาดเป็นห้องทรมาน
การแก้ไฟ/สะพานไม่ทำให้ทดลองฉีด determination สำเร็จเอง และไม่ยืนยันการยอมให้ชิกุอีกคนทดลองเรา

### R07 — พักฟังเรื่องเล็ก ก่อนความเงียบที่แปลกไป

คาเฟ่/ร้านของเก่า/พัสดุ → สวนและชานชาลา → เบาะแสนาฬิกา → ทางทับซ้อนครั้งถัดไปถ้าเลือก → กลับสถานี → เมืองหน้าวัง
รถไฟเป็นฉากนิ่ง ไม่เปิดระบบเดินรถหรือข้ามเมืองจากรูป ห้องร้านไม่ซ่อนประตูมิติทุกห้อง

### R05 — ชีวิตผู้คนก่อนความจริงของราชา

เมือง/ร้าน/ห้องอ่านหนังสือ → ลานหน้าวัง → ห้องครอบครัวเก่า/สวน/เอกสาร → โถงราชา → เหตุการณ์ปลาย SS1 ตามแขนงในโครงเรื่อง
ไม่แทรกชุดปริศนายาวใหม่จนขัดจังหวะดราม่า ประตูมิติใหญ่ยังปิดจนเรื่องอนุญาต
ภาพไม่ได้กำหนดเองว่าฟิวจับใครไว้ที่ห้องไหน ใครตาย หรือจุดคืนร่างชิกุของแต่ละตอนจบ

## 4. ประตูปริศนาและทางวน

ป้าย P/E/C/M/S/D เป็นเครื่องมืออ่านผัง ไม่ใช่ตัวหนังสือที่ต้องแสดงเหนือหัวทุกจุดในเกม
รหัสในภาพเป็นเลขเฉพาะภาพ ต้อง namespaced เช่น r02.ice_route ไม่ใช้ P1 ร่วมกันทุกเมือง

| gateId เสนอ | หน้าที่ | เปิดเมื่อ | เส้นที่ห้ามลัด |

ปริศนาใหม่หลังรูนยังไม่ลงบท: น้ำแข็งกดสัญลักษณ์/เปิดสะพาน, น้ำตกปรับน้ำด้วยคันโยก, แล็บหมุนท่อสามชิ้น, ทางลับโคม/นาฬิกาเป็นแนวเสนอเท่านั้น ไม่ invent คำตอบเฉพาะแล้วอ้างว่าผู้เขียนตกลงแล้ว
รูน: WEST วงกลมฟ้า / SOUTH สามเหลี่ยมแดง / EAST ดาวเขียว คงเดิม; คำตอบปริศนาและลายหนาม/ใบไม้ใช้ CH01 ไม่ถอดจากจำนวนไทล์ในภาพ AI

สถานะที่ต้องรองรับตอนสร้าง:

- locked: ยังไม่ถึงบท/ยังไม่แก้; ห้ามเดินผ่าน แต่อ่านป้าย/ลองปุ่มได้ถ้าอยู่ในช่วงอนุญาต
- active: อยู่ระหว่างลอง; บันทึกปุ่มที่กด/หินที่ขยับตาม SAVE ไม่รีเซ็ตทั้งเมือง
- solved: set flag ครั้งเดียว เปิด gate ทุกจุดของชุดเดียวกัน; ไม่มีแจกของ/เงินทุกครั้งที่เข้า
- loaded: คืนสถานะ gate และ collision พร้อมกัน; ไม่เล่นบทสาธิต/รางวัลซ้ำ
- leaving: ออกจากห้องไปเที่ยวร้านแล้วกลับมาได้ ไม่ทำ NPC/ทางออกหาย

ลาน NPC/ร้าน/SAVE ไม่มี encounter เกิดทับ ใช้ทางวนคืนจุดก่อน gate จนทำชุดบังคับแล้ว
ประตูสองฝั่งเชื่อมกลับห้องเดิม; ทาง VOID A/B คืนทางเข้าของตน ไม่ต่อกันเป็นทางลัดข้ามเมือง
ผิดปริศนาไม่เสียแหวน/เงิน/HP ยกเว้นกติกาที่ผู้เขียนยืนยันแยกต่างหาก; ไม่มีการกระโดดใหม่เพื่อข้ามช่องน้ำ

### พฤติกรรมเข้า–ออก

- เดินถึงหน้าประตู + Z/Enter ยืนยันเมื่ออยู่ระยะ 24 logical px; ไม่ใช้ V เปิดร้านหรือส่งพลัง
- transition จางออก 180 ms → เปลี่ยน roomId/กล้อง/ตำแหน่งปลอดภัย → จางเข้า 180 ms; ระหว่างนั้นรับคำสั่งครั้งเดียว
- ภายในเดินอิสระจริง ก่อนคุยผู้ขาย/เลือกโต๊ะ/ตรวจของ; เมนูซื้อเปิดเมื่อ interact ผู้ขาย ไม่เปิดอัตโนมัติแทนห้อง
- ออกโดยกดที่ประตูเดิม กลับ outsideReturnAnchor หน้าประตูนั้น ไม่ส่งไปอีกมุม/อีกเมือง ไม่เกิดตัวละครหรือของใหม่
- ถ้าไม่มีบทเชิญเข้าบ้าน: แสดงสถานะประตูยังไม่เปิด/อยู่ไม่ได้ตามกติกาที่จะเลือก โดยไม่บังคับสร้างคำพูดใหม่ของตัวหลัก
- มีทางออกที่มองเห็นจากห้องทุกห้อง ไม่มีล็อกผู้เล่นไว้เพื่อบังคับทำเควสบ้าน
- ไม่มี random combat ภายในร้าน/บ้าน/ที่นั่งพัก; เจ้าของบ้านตามสถานะจริง ไม่ปรากฏซ้ำในห้องและฉากไล่ล่าพร้อมกัน

### ข้อมูลที่ต้องเก็บ

roomId, spawnAnchorId, returnAnchor, doorAccessFlags, puzzleFlags, collectedItemIds, shopStock, world/NPC outcomes และ eventSeen flags ที่เกี่ยวข้อง
บันทึกก่อนโหลดคืนเฉพาะข้อมูลตาม SAVE ของเกม ไม่สร้างว่าทุกประตูมี autosave ใหม่เอง
ซื้อล้มเหลวเพราะเงินไม่พอ/กระเป๋าเต็มไม่หักเงิน ไม่ลด stock; สำเร็จหักเงินและเพิ่มของพร้อมกัน
ภาพเก้าอี้/อาหาร/เตาไม่ถือว่าแจก HP หรือเควสครบ ไม่สร้างข้อมูลความทรงจำคู่รักและคำพูดแกนหลักจากภาพแทนบท
