# UNDERFALL — สัญญาขนาดและพิกัด CH00–CH01

> Summary: ขนาดห้อง จุดวางองค์ประกอบ สเกลตัวละคร กล่องคำพูดและศึกที่ใช้ส่งสร้าง โดยคงบท ลายปริศนา และ gate เดิม

รุ่น: UF-LAYOUT-2026-10-09 · แบบที่ใช้อ้างส่งสร้างภายใต้UF-DESIGN-2026-10-09
[ไฟล์ข้อมูลพิกัด](current-layout.json)เป็นแหล่งตัวเลขปัจจุบัน ทั้งสองCHต้องใช้ร่วมกัน ไม่ใช้ขนาดห้อง320×180/ทาง32จากต้นแบบเก่าเป็นคำสั่งปัจจุบัน
ภาพยังเป็นconcept และตัวเลขนี้เป็นworking defaults ไม่อ้างว่าผู้เขียนยืนยันทุกcoordinateหรือเกมผ่านcollisionแล้ว
