# UNDERFALL — งานสร้าง CH00 ใน index_new.html

> Summary: ขอบเขต CH00 และการใช้แผนที่ R00 v1b เป็นโลกเดียว พร้อมแยกผลตรวจ geometry เดิมจากการตรวจ v1 รอบล่าสุด

วันที่ 9 ตุลาคม 2026 ผู้เขียนเลือก [ภาพแมพ v1](../maps/2026-10-08-v1/README.md) กลับมาเป็นต้นแบบภาพสำหรับรอบนี้ แทนการเลือกภาพ v2 ก่อนหน้า งานผัง/ภาพ/การเดินรอบใหม่นี้ต้องมีผลตรวจของตัวเอง ผลของ geometry เดิมด้านล่างเป็นหลักฐานย้อนหลัง

## ขอบเขตที่เล่นได้

สร้างใหม่ตาม CH00-r2: ตกครบรอบ 1 ปี 3 เดือน → เสียง Void แทรกเจ็ดบรรทัด → ลงพื้น/เจ็บหรือไม่เจ็บ → ฝึกเดิน → ดอกไม้/กวาง/ขวด → X/C/V/B → กล่องมัฟฟิ้นและทางรากไม้ → ป่าไม้ใหญ่/คำถามความทรงจำ → คนสวมหมวกและสองแขนง

- ช่วย: เข้าไปหา ถูกโจมตีและตกเข้ารอยแยก ไม่ได้แหวนหรือ N
- ไม่ช่วย: สำรวจต่อ เรียก V เปิดหินจิ้งจอก เข้าสวน/น้ำตก รับแหวนหนึ่งชุบ และกด N ปลดมือขาวสองข้างรูมืด จากนั้นถูกโจมตีและเข้ารอยแยก
- จบตรงสะพาน `rift_bridge`, `chapter=ch01_pending`, `resumeScene=10.10`, `name=null`, `phone=false`
- **CH01 ยังไม่ติดตั้ง** ไม่เล่นตำนาน ตั้งชื่อ ฟลาววี่ รูน ทอเรียล หรือพบแซนในไฟล์นี้ ไม่เปลี่ยนบท/โครง/ใบงานเพื่ออ้างว่าเนื้อหานั้นทำแล้ว

## แบบที่ใช้และงานภาพที่ยืนยันล่าสุด

- ผู้เล่น R5 รุ่นขาสั้น/หุบ/เรียวที่ผู้เขียนรับรอง: 12 เฟรมเดิน 24×32 และ 6 ท่าฉาก 40×32 ไม่แก้พิกเซลต้นฉบับ
- STAT ใช้ภาพดาวที่หน้าอก `player-stat/v1` แยกจากตัวเดินและอุปกรณ์
- เมนูเดิน `overworld-panels-r2`: ITEM/STAT/CELL/SOUL ซ้าย สถานะย่อด้านล่าง pane ขวาเมื่อตัดสินใจเปิดหมวด ฉาก/คูลดาวน์พักจริง ไม่คัดลอกของ/เงิน/โทรศัพท์จากต้นแบบ UI
- R00 ใช้ภาพ `design/maps/2026-10-08-v1/01-r00-forest-and-sacred-grove-v1b.png` เป็นต้นทาง ตัดกรอบ `[18,50,1516,952]` และใช้สเกล 1.25 ตามรอบที่เลือกใหม่; ต้นไม้ ทางเดิน โขดหิน ลานสวนและน้ำตกต้องอยู่ตามภาพนี้ ดู [บันทึกพื้นที่ v1](../maps/2026-10-08-v1/MAP_NOTES.md)
- แผนผัง CH00 เป็นโลก R00 เดียว ใช้พิกัดโลกชุดเดียวกับภาพต้นทาง ห้อง/ช่วงเนื้อเรื่องเป็นพื้นที่ภายในโลกนี้ กล้องติดตามตำแหน่งผู้เล่น การข้ามช่วงต้องรักษาตำแหน่งต่อเนื่อง
- งานภาพล่าสุดเป็นฉาก 2D แบ่งชั้นแบบ Undertaleที่สร้างและตรวจแล้ว: พื้น tile น้ำ หน้าผา สะพาน บันได และวัตถุแยกชิ้น; ต้นไม้88จุดเรียงตามตำแหน่งเท้าร่วมกับผู้เล่น/NPC ไม่วาดภาพแมพเต็มเป็นพื้นฉาก
- ต้นไม้และองค์ประกอบฉากสูงอ้างรูปร่าง สี texture และตำแหน่งจาก v1b ที่สเกล 1.25 โดยรักษาเส้นทาง/anchor ของผัง R00 เดิมและสไปรต์ R5 ขนาดเดิม ภาพแมพ PNG เต็มกับผล cleanup เก็บเป็นภาพอ้างอิง/debug และหลักฐานที่มา ไม่ใช้เป็นพื้นโลกภาพเดียวใน renderer แบ่งชั้นที่ยืนยันล่าสุด
- เพิ่มการเคลื่อนไหวตามตำแหน่งองค์ประกอบจริงในภาพ ได้แก่ เส้นแสงน้ำตก ละออง/หิ่งห้อย และแสงดอกไม้เมื่อเดินผ่าน; การแสดงภาพความละเอียดสูงกับขนาดตัวชนเป็นคนละข้อมูล ต้องตรวจว่าภาพกับพื้นที่เดินตรงกัน
- [manifest แมพ R00 v1b](../../assets/maps/r00-v1/manifest.json) ระบุแหล่งภาพ ภาพอ้างอิงและสไปรต์กล่อง/ประตู/รอยแยกที่แยกจากต้นฉบับ พร้อม cleanup mask เฉพาะบริเวณและผลพิกเซลนอก mask ไม่เปลี่ยน; เป็นหลักฐานการเตรียมภาพ ไม่ใช่ผลยืนยัน renderer แบ่งชั้น พื้นที่เดินหรือการเล่น
- คนสวมหมวกใช้แพ็ก `hooded-stranger/v1`: สี่ท่าจากดีไซน์ฟิวมอนสเตอร์ R2b บังหน้า ไม่แสดงชื่อในเกม ดู [พรอมต์/ต้นฉบับ](../../assets/characters/hooded-stranger/v1/hooded-stranger-v1-prompts.md) และ [manifest](../../assets/characters/hooded-stranger/v1/manifest.json)
- เสียงขวดเป็น `???` เท่านั้น เสียง Void ไม่มี portrait/เงาร่าง ไม่มีมือเจ็ดข้างหรือเฉลยชื่อก่อนจังหวะในเรื่อง
- เสียงทั้งหมดสังเคราะห์ใหม่ ไม่ใช้เพลง/เสียงเกมอื่นโดยอัตโนมัติ

## แหล่งแก้ไขและวิธีสร้าง

`src/ch00/shell.html`, `runtime.css`, `renderer.js`, `storage.js`, `ui.js`, `runtime.js` เป็น source; ผังโลก R00 ชุดเดียวอยู่ใน `src/ch00/map-layout.json` มี anchors/routes/stage gates ในหน่วยโลก และ navPolygons ในพิกัดภาพต้นฉบับตาม transform ที่ระบุ

วัตถุแยกชิ้นอยู่ใน `src/ch00/map-entities.json`: ต้นไม้มีจุดเท้า/ขนาด/ชนิดสไปรต์ พร้อมสะพาน บันได ขอนไม้และแนวหน้าผาในพิกัดภาพต้นทาง การวางวัตถุต้องคงพื้นที่เดินจาก navmesh เดิม และใช้ depth sorting ใน renderer กับตัวละครจริง

`tools/build-ch00.cjs` ดึงบทตรงจาก [story.md](../../story.md) กับ [ใบงาน CH00](../../ch00.md) และฝังผัง R00/manifest ภาพ/[แพ็ก R5](../../assets/characters/player-r5/v1/README.md)/[แบบ UI](../interface/v1/interface-handoff.md) โดยอ่าน [ข้อมูลขนาดร่วม](current-layout.json) สำหรับสัญญาบท/พื้นที่อื่นตามขอบเขตที่ยังไม่ติดตั้ง

Canvas แสดงภาพรอบนี้ใช้ 1600×900 ภายใต้หน่วยโลก 400×225 การเดินและวาดกล้อง/สไปรต์เก็บพิกัดทศนิยม กล้องเลื่อนด้วย `1−exp(−10dt)` และจังหวะเดินผูกกับระยะที่เดินจริง จึงไม่เลื่อนเฟรมก้าวต่อเมื่อหยุดหรือชนจนไม่เคลื่อน; ขนาด canvas แสดงภาพไม่เปลี่ยน native PNG หรือ foot collider ของ R5

```powershell
& 'C:\Program Files\nodejs\node.exe' tools/build-ch00.cjs
& 'C:\Program Files\nodejs\node.exe' tools/check-ch00.cjs
& 'C:\Program Files\nodejs\node.exe' tools/run-r00-map-qa.cjs
& 'C:\Program Files\nodejs\node.exe' tools/run-r00-guardrails.cjs
```

อย่าแก้ HTML ที่ build แล้วเพียงที่เดียว เพราะ build รอบถัดไปจะประกอบใหม่ เปิด `http://127.0.0.1:4188/index_new.html`; เกมใหม่ฝัง atlas/บท/โค้ดไว้ใน HTML ไม่ต้อง fetch JSON ระหว่างเล่น เก็บ index.html ข้างกันสำหรับเปิดตอนเก่าในประวัติ

## SAVE และข้อมูลที่ห้ามทิ้ง

SAVE จริง `underfall.save.v1`, schema 1, content `CH-2026-10-09`, design `UF-DESIGN-2026-10-09`; รอบ R00 v1b ใช้ layout `UF-R00-V1B-2026-10-09` และ engine `UF-CH00-2026-10-09-r2`

`?qa=1` ใช้ได้เฉพาะ localhost/127.0.0.1 แยกเป็น `underfall.qa.save.v1` และมีเครื่องมือทดสอบ หน้าเล่นปกติไม่มี API แก้ฉากของ QA ไม่ใช้ `underfall.interface-preview.v1` ร่วมกับเกมจริง

## ผลตรวจและข้อจำกัด

### หลักฐาน geometry เดิมก่อนเลือกแมพ v1 ใหม่

- Browser เดิม: flow 24 ข้อ, help 18 ข้อ, guardrails 24 ข้อ รวม 66 assertions; เป็นผลของ `UF-CH00-2026-10-09-r1` ไม่ใช่การตรวจภาพ/ผัง R00 v1b รอบใหม่นี้
- Static เดิม: 24 ข้อ รวม Unicode เจ็ดบรรทัด บทเจ็บ/ไม่เจ็บ และ hash ของเกมเดิม/บท/โครง/ใบงาน/PNG R5 ที่ยังไม่เปลี่ยน
- geometry เดิมเล่นด้วย keyboard ผ่าน physics/collision ทั้งสองแขนง ใช้นาฬิกาเบราว์เซอร์ควบคุม; flow/help ไม่ warp ข้ามเรื่อง ส่วน guardrails ใช้ warp/ฉีด storage เสียเฉพาะทดสอบ
- การวัดลาน 480×290 ที่ sample grid 4 px ไม่มีจุดชน และทางตัวอย่าง 80 px ในสองห้อง เป็นการวัดเฉพาะผังเดิม จึงใช้ยืนยันพื้นที่เดิน v1b ไม่ได้

### หลักฐานภาพร่าง R00 v1b ก่อนยืนยัน renderer แบ่งชั้น

Build ภาพร่างที่ใช้ PNG แมพเต็มกับชั้นพุ่มไม้เคยผ่านการประกอบด้วย `UF-CH00-2026-10-09-r2` / `UF-R00-V1B-2026-10-09`; ขนาด 3,960,888 bytes ตามรายงานวันที่ 9 ตุลาคม 2026 ก่อนผู้เขียนยืนยันการสร้างโลกแบ่งชั้นจริง ผลนี้เป็นหลักฐานภาพร่างรอบก่อนหน้า

Static ภาพร่างรอบก่อนหน้าผ่าน **36 ข้อ**: ตรวจ source v1b/crop/scale/shared world/anchor transform/nav polygons/safeSpawn, manifest และข้อมูล PNG ที่ฝังใน build, บท/Unicode และ hash ต้นฉบับ **11 ไฟล์** ที่ยังเดิม รวม PNG R5 กับภาพ v1b การตรวจอ่านหลักฐาน cleanup mask ซึ่งระบุพิกเซลเปลี่ยนนอก mask เท่ากับ 0; ผลนี้ยังไม่ได้ตรวจว่ามีพื้น/หน้าผา/วัตถุแยกชั้นจริงและไม่ทดแทนการเล่นหรือรับรองภาพ

### การตรวจ renderer แบ่งชั้น R00 v1b รอบล่าสุด

สถานะ: **สร้างโลกแบ่งชั้นจริงและตรวจใน Chromium แล้ว** ไม่มี mapBackground ใน assetsของเกม; พื้น/น้ำ/หน้าผาเป็นชั้นที่ประกอบจากไทล์และกรอบพื้นที่ ส่วนต้นไม้88จุดเป็นสไปรต์ลำต้น/พุ่มแยกจากต้นทาง เรียงความลึกกับตัวละครและคงตำแหน่งจากv1b

- `output/playwright/r00-map-flow-result.json`: 66 assertions ผ่าน เล่นจากเริ่มใหม่ด้วย keyboardจริงทั้งช่วย/ไม่ช่วย ครบขวด/มัฟฟิ้น/C/ทางลับ/V/แหวน/N/SAVE และจบที่10.10 ไม่warpข้ามเรื่อง
- `output/playwright/r00-guardrails-result.json`: 50 assertions ผ่าน migration/สำรอง/ledgerแหวน/ข้อมูลเสีย/พื้นที่บันทึกเต็ม/ลองใหม่/คูลดาวน์/เมนู และการคงHPสองแขนง; fixtureที่ใช้ฉีดข้อมูลเป็นการทดสอบระบบ ไม่ใช่หลักฐานเดินเรื่อง
- `output/ch00/static-result.json`: 41 checks ผ่าน แยกโลกแบบtile/objectsจริงและรักษาhashต้นฉบับ11ไฟล์ รวมบท/โครง/เกมเก่า/PNG R5/ภาพv1b
- พื้นรุ่นปรับใน `assets/maps/r00-surfaces-v2` เลือกหย่อมสีเงียบจากต้นฉบับเพื่อไม่ให้หิน/ดอกไม้ติดเป็นลายซ้ำ และแยกดอกไม้เป็นวัตถุ; กรอบพื้นที่/เส้นทาง/จุดสำคัญไม่เปลี่ยน บริเวณเชื่อมสวนใช้พื้นหญ้าที่มองเห็นเดิมต่อกรอบเดิน ไม่เพิ่มทางลัดหรือฉากใหม่

ภาพจุดตรวจจากfixtureใน `r00-layered-*-preview.png` ใช้ตรวจหน้าตาเฉพาะจุด ส่วนภาพ `r00-do_not_help-*` / `r00-help-*` มาจากการเล่นผ่านเรื่องจริง ภาพก่อนหน้าที่เป็นPNGทั้งผืนไม่ใช่หลักฐานรับรองrendererปัจจุบัน การรับรองหน้าตาสุดท้ายยังเป็นการตัดสินใจของผู้เขียน

รายงาน JSON ใน `output/ch00/` ต้องมี engine/layout และวิธีสร้างฉากตรงกับรอบที่อ้าง; ภาพจริงใน `output/playwright/ch00-*.png` ต้องมาจาก build รอบนั้น ผลภาพร่าง PNG เต็มใช้ยืนยัน renderer แบ่งชั้นไม่ได้ แม้ engine/layout ยังเป็นรหัสเดียวกัน รายงานหรือภาพเก่าไม่เปลี่ยนเป็นหลักฐานใหม่จากการแก้เอกสาร
