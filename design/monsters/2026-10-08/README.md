# UNDERFALL — ภาพร่างมอนสเตอร์ ชุด 2026-10-08

> **เอกสารประวัติ ไม่ใช่คำสั่งแบบล่าสุด:** เลือกไฟล์ตาม [design-current.md](../../../design-current.md) ก่อน ชุดที่ใช้ตอนนี้คือผู้เล่นR5/ร่างพิเศษR4/ตัวอื่นR2 แมพv2 portrait v1 และเสียงVoidเห็นตัวครั้งแรกหลังต้นไม้SX03 เนื้อหาด้านล่างเก็บตามช่วงที่สร้างเดิม ไม่ให้ใช้ข้อเก่าทับตัวตน/สเกล/กติกาล่าสุด ภาพบางไฟล์ในรุ่นนี้ยังถูกเลือกใช้เป็นแหล่งอ้างอิงตามดัชนีปัจจุบัน

สถานะ: **ภาพคอนเซปต์เพื่อเลือกหน้าตา ยังไม่ได้แทนสไปรต์ในเกม**  
สร้างตามคำขอ: pixel 8-bit-inspired มีรายละเอียดสี แต่ไม่ฉูดฉาด  
วิธีสร้าง: เครื่องมือ image generation ในตัว ไม่ใช้ CLI/API fallback

## ขอบเขต

รวม **6 ชีต / 43 ช่องออกแบบ** ตามตัวละคร/ร่างพิเศษ/รูปแบบตัวรองที่มีใน story.md และโครงเรื่อง.md ณวันที่สร้าง รวมคนในตัวหลักด้วยแม้บางคนไม่ใช่มอนสเตอร์ นับร่างเดิม/NEO, แอสเรียลเด็ก/Hyperdeath, ชิกุจิ้งจอก/หยวน และฟลาววี่ปกติ/กลายพันธุ์เป็นแบบแยก

ไม่ใช่ข้อสรุปว่าทุกตัวในจักรวาลในอนาคตมีชื่อหรือหน้าตาครบแล้ว รายชื่อมอนเมืองอื่นที่ยังไม่ได้คิดไม่ได้เติมเป็นตัวหลักใหม่เอง

## ทิศทางภาพ

- ใช้พิกเซลที่เห็นเป็นก้อนชัด เส้นรอบนอกและสีเงาอ่านทรงได้
- ใช้ครีม/เทา/เขียวหม่น/น้ำเงินเทา/ม่วงหม่น/แดงน้ำตาล/ทองเก่า ไม่ใช้แสงนีออนหรือเอฟเฟกต์สีรุ้ง
- แยกทรงตามบุคลิก: คนดูแลอ่อนโยน, ตัวขี้กลัวห่อไหล่, คนดื้อกอดอก, ผีลอยต่ำ, คนขายของมีสิ่งที่กำลังทำ
- สไปรต์เกมจริงต้องทำอีกขั้น: เลือกขนาดตรรกะ, ล้างกริด/ข้อความ/พื้นหลัง, คุมpalette/alpha และทำidle/attack/walkตามงานที่ผู้เขียนมอบหมาย ภาพชีตชุดนี้ยังไม่ใช่sprite atlasที่วางเข้าเกมได้ทันที
- เป้าขนาดในพรอมต์เป็นแนวทาง ไม่อ้างว่าตรวจผ่านการจำกัดสี16สีหรือขนาด32พิกเซลทางเทคนิคแล้ว

## สิ่งที่ยังเป็นแบบเสนอ

คำว่า DRAFT / แบบเสนอ หมายถึงรูปลักษณ์ที่กำลังเลือก ไม่ใช่ฉากหรือข้อมูลcanonที่ล็อกแล้ว

- มาเรีย: รูปแบบมอนหมาป่าหญิงและชุดเกราะเป็นข้อเสนอภาพ ไม่เติมสายพันธุ์/บาดแผลอดีตเข้าบท
- คิน ฟิว ริน และหยวน: หน้าตา/ผม/เครื่องแต่งกายที่ยังไม่มีแบบยืนยันเป็นข้อเสนอ ไม่เปลี่ยนสไปรต์ผู้เล่นผมเงินที่มีอยู่
- นักวิทยาศาสตร์อีกเส้นเวลา: แสดงแบบนักวิทยาศาสตร์แยกจากหยวน ไม่ตัดสินว่าเป็นตัวตนจากการลบ
- VOID ECHO: เงาต้นแบบสำหรับตัวตนที่ยังไม่รู้ชื่อ ไม่เฉลยเจตนา/อัตลักษณ์หรือเพิ่มประวัติ
- ฟลาววี่กลายพันธุ์: รูปร่างตัวอย่างสำหรับเส้นผสม ไม่ใช่การยืนยันแบบบอสสุดท้าย
- คนดูแลสวน/นักเก็บเสียง/หุ่นผู้ช่วย/คนจุดโคมและมอนกึ่งของเหลว: ภาพเสนอจากบทบาทที่มีอยู่ ไม่มอบชื่อหลักหรือเพิ่มเควสใหม่
- รูปเต็มของชิกุ/หยวนมีไว้ให้ผู้เขียนเลือกแบบ ห้ามนำไปเผยในCH00–CH01แทนเสียง???หรือฉากที่มีเพียงมือบางส่วน
- งานนี้ไม่แก้ story.md, โครงเรื่อง.md, CLAUDE.md, HTML หรือสไปรต์เดิม
