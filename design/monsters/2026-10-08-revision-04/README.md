# UNDERFALL — ชุดงานภาพ R4 (เก็บเป็นประวัติ)

> **เอกสารประวัติ ไม่ใช่คำสั่งแบบล่าสุด:** เลือกไฟล์ตาม [design-current.md](../../../design-current.md) ก่อน ชุดที่ใช้ตอนนี้คือผู้เล่นR5/ร่างพิเศษR4/ตัวอื่นR2 แมพv2 portrait v1 และเสียงVoidเห็นตัวครั้งแรกหลังต้นไม้SX03 เนื้อหาด้านล่างเก็บตามช่วงที่สร้างเดิม ไม่ให้ใช้ข้อเก่าทับตัวตน/สเกล/กติกาล่าสุด ภาพบางไฟล์ในรุ่นนี้ยังถูกเลือกใช้เป็นแหล่งอ้างอิงตามดัชนีปัจจุบัน

**ชุดปัจจุบันให้เริ่มที่ [README R5](<C:/Users/wisu/Desktop/โปรเจคครบรอบ + 2ปี/design/monsters/2026-10-08-revision-05/README.md>)** ผู้เขียนปรับเฉพาะผู้เล่นชีต07ให้ตัวเล็กผอม กางเกงขาสั้น ขาเรียว และเทียบส่วนสูงกับแอสเรียลร่างเด็ก ชีต03และตัวอื่นยังใช้ตามเดิม ข้อมูลด้านล่างเป็นประวัติขณะออก R4

วันที่8ตุลาคม2026  
สถานะ: **ภาพร่างพิกเซล8-bit-inspired ยังไม่ติดตั้งในเกม**  
วิธีสร้าง: built-in image generation / edit พร้อมภาพอ้างอิง ไม่ใช้CLI/API fallback

## ปรับเฉพาะแอสเรียล Hyperdeath

เปลี่ยนเฉพาะช่องล่างกลางของชีต03 ตามภาพใหม่สองภาพที่ผู้เขียนส่ง:
- [ภาพชุด/คอเสื้อ](<C:/Users/wisu/Pictures/Screenshots/สกรีนช็อต 2026-10-08 050046.png>)
- [ภาพสัดส่วน/ผ้าคลุม](<C:/Users/wisu/Pictures/Screenshots/สกรีนช็อต 2026-10-08 050039.png>)

สิ่งที่ปรับ:
- รูปร่างเพรียวเล็ก ไหล่/เอวแคบ แต่เน้นความสูงด้วยลำตัวและช่วงขาที่ยาวกว่าแบบก่อน
- ยังคงเป็นมอนสเตอร์แพะขาววัยเยาว์ มีหูยาว เขาโค้งและขนผมสีอ่อน ไม่เปลี่ยนเป็นมนุษย์
- ชุดม่วงเข้ม–ครามขอบครีม คอเสื้อสูงปลายชี้ ตราที่อก รายละเอียดทองเล็กน้อย แขนเสื้อขาว
- มีผูกเอวฟ้า–ม่วงอ่อนตามภาพ ชายชุดแยกให้เห็นขาขาวและเท้าแพะ ไม่ใส่เกราะหนัก/บูท
- ผ้าคลุมเข้มมีซับ/ขอบอ่อน พริ้วออกด้านหนึ่ง คุมให้ลำตัวดูเพรียว
- ใช้ท่ายืนมือหนึ่งยกพร้อมดาวขาวทองเล็กๆ ไม่ใส่ฉากดาว/แสงรุ้งเต็มภาพหรือคัดลอกลายน้ำ
- คงสไตล์พิกเซลและระดับสีของชุดปัจจุบัน ไม่เพิ่มความสดอีก10–15%ซ้ำทุกรุ่น

ช่องอื่นในชีต03ไม่เปลี่ยน: ชิกุจิ้งจอก9หาง/7มือ, หยวนผมดำกับ7มือขาววงกลางสี, อีกเส้นเวลา, VOID ECHO และฟลาววี่ร่างพลังไม่สมบูรณ์
ร่างเด็กของแอสเรียลในชีต02ไม่เปลี่ยน ไม่แก้บท/พลัง/เส้นจบ/เกมหรือสไปรต์จริง

## การตรวจและขอบเขต

- ตรวจภาพด้วยตาว่าแอสเรียลยืนเต็มตัว สัดส่วนเพรียว/ขาชัด ชุดใกล้ภาพอ้างอิง และไม่ล้นช่อง
- หยวนยังมี7มือลอยตัวมือขาว/วงกลาง7สี ไม่มีการคืนแบบมือทั้งข้างสีจากR2
- คัดลอกPNGเข้าโฟลเดอร์งานภาพนี้ ตรวจSHA256ตรงกับไฟล์ผลสร้างต้นทาง
- เก็บR1–R3ไว้เป็นประวัติ ไม่เขียนทับภาพเก่าหรือassets/sprites
- ชีตยังมีข้อความ/กรอบ/พื้นหลัง จึงไม่ใช่sprite atlasหรือแอนิเมชันพร้อมนำเข้า ต้องจัดทำในงานสร้างจริงภายหลัง
