# UNDERFALL — งานภาพ R2 (เก็บเป็นประวัติ)

> **เอกสารประวัติ ไม่ใช่คำสั่งแบบล่าสุด:** เลือกไฟล์ตาม [design-current.md](../../../design-current.md) ก่อน ชุดที่ใช้ตอนนี้คือผู้เล่นR5/ร่างพิเศษR4/ตัวอื่นR2 แมพv2 portrait v1 และเสียงVoidเห็นตัวครั้งแรกหลังต้นไม้SX03 เนื้อหาด้านล่างเก็บตามช่วงที่สร้างเดิม ไม่ให้ใช้ข้อเก่าทับตัวตน/สเกล/กติกาล่าสุด ภาพบางไฟล์ในรุ่นนี้ยังถูกเลือกใช้เป็นแหล่งอ้างอิงตามดัชนีปัจจุบัน

วันที่8ตุลาคม2026 · ภาพร่างพิกเซล8-bit-inspiredสร้างด้วยเครื่องมือภาพในตัว

**ชุดปัจจุบันให้เริ่มที่ [README R3](<C:/Users/wisu/Desktop/โปรเจคครบรอบ + 2ปี/design/monsters/2026-10-08-revision-03/README.md>)** ผู้เขียนส่งภาพใหม่แทนผู้เล่นและหยวนหลังสร้างR2แล้ว จึงไม่ใช้ชีต03/07R2เป็นแบบล่าสุด ส่วนอีก6ชีตยังใช้ตามรายการR3

## สิ่งที่ปรับใน R2

- ฟิวและคินต้องเป็นมอนสเตอร์ ไม่ใช่มนุษย์: เสนอแบบแรคคูนและนกฮูกตามลำดับ
- ปรับหยวน/นักวิทยาศาสตร์อีกเส้นเวลา/แอสเรียล/แอสกอ/ฟลาววี่ไม่สมบูรณ์ตามภาพอ้างอิงชุดแรก
- คงพิกเซล8-bit-inspired เพิ่มความสดของสีตามเป้าหมาย10–15%โดยไม่ได้อ้างว่าวัดเชิงฟิลเตอร์ทุกพิกเซล
- ปรับมอนรองให้ใกล้Undertaleและเพิ่มชีตMuffetกับ8ตัวรอง
- เพิ่มผู้เล่นFrisk-inspiredพร้อมตัวอย่างท่า ก่อนถูกแทนด้วยภาพผู้เขียนในR3
- แก้Asgoreให้รูป/ตรีศูลอยู่ครบในช่อง และปรับสัดส่วนผู้เล่นเป็นr2b
