# UNDERFALL — ชุดงานภาพปัจจุบัน R5

> **ชุดอ้างอิงปัจจุบัน:** ปัจจุบัน: UNDERFALL — ชุดงานภาพปัจจุบัน R5; อ่านdesign-currentเพื่อเลือกเวอร์ชันและไม่อ้างภาพเป็นruntime อ่าน [design-current.md](../../../design-current.md) เพื่อเลือกเวอร์ชันและแยกข้อยืนยัน/ค่าตั้งต้น/งานที่ยังไม่สร้าง; [INDEX.md](../../../INDEX.md) เป็นทางเข้าเอกสารทั้งหมด

วันที่: 8 ตุลาคม 2026
สถานะ: ภาพร่างพิกเซลสำหรับใช้อ้างอิง **ยังไม่ติดตั้งสไปรต์ในเกม**
เครื่องมือ: built-in image_gen ของ Codex ไม่ใช้ CLI/API fallback

## เปลี่ยนเฉพาะผู้เล่น

ภาพล่าสุดของผู้เขียนกำหนดตัวเล็ก ผอม กางเกงขาสั้น ขาเรียว และส่วนสูงเท่ากับ **แอสเรียลร่างปกติ**
รอบนี้เทียบแอสเรียลร่างเด็กเสื้อเขียวในช่องขวาบนชีต02 ไม่เทียบร่าง Hyperdeath เสื้อม่วงในชีต03

- ลดหัว ไหล่ และลำตัวที่กลมหนาจากผู้เล่น R3 ให้ทรงเพรียวขึ้น แต่คงความน่ารักวัยเยาว์
- กางเกงสั้นเข้มอ่านทรงได้ ไม่ถูกเสื้อยาวปิดจนเหมือนกระโปรง
- ขาเปล่าเรียวช่วงต้นขา–น่องตามภาพใหม่ แทนถุงน่องเทาของ R3
- รองเท้าน้ำตาลหุ้มข้อเตี้ย แทนบูทสูง เพื่อไม่บังช่วงขา
- คงผมบ๊อบน้ำตาล ใบหน้าอ่อนโยน และเสื้อน้ำเงินเข้ม/ครามแถบชมพูสองแถบจากแบบก่อน เพราะคำขอใหม่เน้นสัดส่วนและทรงขาสั้น
- คงสไตล์พิกเซล 8-bit และระดับสีเดิม ไม่เพิ่ม saturation 10–15% ซ้ำอีกครั้ง
- ใช้เฉพาะตัวละครในภาพอ้างอิง ไม่เอาท่ากลับหัว ข้อความ GAME OVER หรือหัวใจแตกมาใส่ในโมเดล
- ชีตมี FRONT/SIDE/BACK/IDLE/WALK และช่อง SAME HEIGHT ยืนคู่แอสเรียลร่างเด็ก แทนช่องศึกษา SOUL LIGHT เดิม
- การเอา SOUL LIGHT ออกจากชีตนี้ไม่ได้แก้ฉากหัวใจแดงหรือยกเลิกพลังในเรื่อง ไม่มีดาวทองติดตัวเป็นชิ้นส่วนเสื้อ

## ส่วนสูงตอนสร้างสไปรต์จริง

กำหนด actorHeight.player = actorHeight.asrielNormal ที่สเกลโลกเดียวกันและยืนบน baseline เดียวกัน
ไม่ขยายร่างแอสเรียลเพื่อให้ดูเท่าผู้เล่น ไม่ลดตัวผู้เล่นด้วยการซูมกล้องเฉพาะคน
ภาพเทียบเป็นการศึกษาแบบและสเกล ยังไม่ใช่ข้อมูล sprite bounds/hitbox ที่ตรวจแล้วว่าเท่ากันทุกพิกเซล
ตอนสร้างจริงต้องกำหนด logical height ร่วมกัน ตรวจจาก crown ของร่างถึงพื้นรองเท้า และแยกปอยผม/หู/เอฟเฟกต์ออกจากกติกาวัดให้ชัด
ไม่กำหนดความสูงจริงเป็นเซนติเมตรหรือเปลี่ยนความเร็วเดิน/จุดชนจากภาพนี้เอง
